Project Overview
Hungry is a modern, responsive food delivery web application designed to streamline the meal ordering process, with a specific focus on customized tiffin and subscription-based meal planning.

The application targets users who require reliable, pre-scheduled meal options, such as tiffin service agencies, hostel residents, and university day scholars. 
By shifting the focus from instantaneous delivery to reliable, planned meal schedules, Hungry provides a specialized, user-centric approach to food service.

---

✨ Key Features
Custom Meal Planning: Users can build and customize their meal/tiffin menu according to their dietary preferences and schedule.

Time-Based Order Scheduling: Orders are placed not for immediate delivery, but according to pre-defined time slots or recurring subscription periods.

Intuitive UI/UX: A clean, component-driven interface built with React ensures a smooth user experience, especially around meal selection and calendar-based scheduling.

Scalable Architecture: Designed with modern React practices to ensure easy maintenance and future scaling of features (e.g., adding payment gateways or full server integration).
